MongoDB & Mongoose Revision - Key Concepts
=============================================

MongoDB is a NoSQL document database. Instead of tables with rows and columns (like SQL),
MongoDB stores data as flexible JSON-like documents inside collections.

Key Terminology:
- Database    → A container for collections (like a SQL database)
- Collection  → A group of documents (like a SQL table)
- Document    → A single record stored as BSON/JSON (like a SQL row)
- Field       → A key-value pair in a document (like a SQL column)
- _id         → Auto-generated unique identifier for every document (ObjectId)
- BSON        → Binary JSON — MongoDB's internal storage format

MongoDB vs SQL:
- SQL Database    → MongoDB Database
- SQL Table       → MongoDB Collection
- SQL Row         → MongoDB Document
- SQL Column      → MongoDB Field
- SQL Primary Key → MongoDB _id (ObjectId)
- SQL JOIN        → MongoDB populate() or $lookup

Mongoose:
- Mongoose is an ODM (Object Document Mapper) for MongoDB and Node.js.
- It provides schema-based modeling — you define the structure of your documents.
- It adds validation, type casting, query building, hooks, and more on top of MongoDB.
- Without Mongoose, you'd use the native MongoDB driver (lower-level, more manual work).

ObjectId:
- Every document automatically gets an _id field with a unique ObjectId.
- ObjectId is a 12-byte value: 4 bytes timestamp + 5 bytes random + 3 bytes counter.
- Example: ObjectId("64abc123def456789012abcd")
- You can extract the creation timestamp from an ObjectId.

CRUD Operations:
- Create → Model.create(), new Model().save(), Model.insertMany()
- Read   → Model.find(), Model.findById(), Model.findOne()
- Update → Model.findByIdAndUpdate(), Model.updateOne(), Model.updateMany()
- Delete → Model.findByIdAndDelete(), Model.deleteOne(), Model.deleteMany()
